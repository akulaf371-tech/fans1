# FANS1 — фанатский блог о Формуле-1

Статический блог, который собирается из `content/posts.json` и хостится на Vercel.
Контент пишется в **локальной админке**: запусти и открой http://127.0.0.1:8765

## Запуск админки

```bash
cd ~/Рабочий\ стол/fans1
python3 admin/server.py
```

- Пишешь заголовок, текст, перетаскиваешь фото/видео — они автоматически
  грузятся в бесплатное облако (**imgbb** для картинок, **Cloudinary** для
  фото + видео) или, если облако не настроено, лежат локально в `public/uploads/`.
- Кнопка «🚀 Опубликовать» пересобирает сайт в `_site/` — предпросмотр сразу
  доступен в админке по ссылке «Предпросмотр сайта».

## Публикация на Vercel (один раз)

```bash
cd ~/Рабочий\ стол/fans1/_site
vercel login            # откроет браузер
vercel --prod --yes     # зальёт папку _site
```

Обновление после новых постов — те же две команды, либо просто:
`vercel --prod --yes` из `_site`.

## Настройка облака для медиа

Внизу админки:

1. **imgbb** — бесплатный хостинг картинок: зарегистрируйся на api.imgbb.com,
   скопируй API-ключ в админку. До 32 МБ на файл.
2. **Cloudinary** — принимает и фото, и видео (бесплатный тариф с щедрыми
   лимитами): Console → Settings → Upload → добавь *unsigned* upload preset,
   имя пресета и имя облака впиши в админку.

## Как устроено

```
fans1/
├── admin/            # локальная админка (python3 admin/server.py)
│   ├── server.py     # сервер: API постов, загрузка медиа, вызов сборки
│   └── static/       # интерфейс админки
├── scripts/build.py  # сборщик: posts.json + templates → _site/
├── content/posts.json# база постов
├── templates/        # шаблоны главной и страницы поста
├── assets/           # css/js/favicon сайта
└── _site/            # готовый статический сайт (то, что заливается на Vercel)
```

Markdown-разметка: `**жирный**`, `*курсив*`, `[ссылка](https://...)`,
пустая строка = абзац; ссылка на YouTube отдельной строкой превращается во встроенный плеер.
